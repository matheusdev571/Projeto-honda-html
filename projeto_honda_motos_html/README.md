# Projeto HTML Avançado — Honda Motos

Projeto acadêmico desenvolvido para a atividade de HTML Avançado.

## Tema
O projeto foi inspirado no universo do site Honda Motos, especialmente na organização por categorias de motocicletas, serviços, pós-venda e contato. A referência consultada foi o site oficial da Honda Motos: https://www.honda.com.br/motos/

**Importante:** este projeto não é oficial da Honda e não reproduz o site original. Ele utiliza o tema apenas como inspiração para fins educacionais.

## Tecnologias
- HTML5
- Sem CSS
- Sem JavaScript

## Estrutura
- `html/` — páginas HTML
- `img/` — imagens locais
- `audio/` — áudio local
- `video/` — vídeo local

## Recursos utilizados
- Tags semânticas: header, nav, main, section, article, aside e footer
- Tabelas
- Formulários
- `audio` com controls
- `video` local com controls
- `figure` e `figcaption`
- `date`, `file`, `color` e `range`
- `required` e `placeholder`
- `datalist`
- `details` e `summary`
- `abbr`, `mark`, `blockquote`, `cite`, `del`, `ins`/elementos de texto avançados
- `progress`
- Meta tags
- Navegação entre múltiplas páginas
